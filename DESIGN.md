# Panel direction

An operational tool: preserve the existing dark-blue surface and prioritize current state, progress and the next action. System typography, fixed scale, subtle rules and spacing in multiples of 4 px. Light blue signals preview/primary actions, pink deletion, amber waiting and green completion.

Order: title/language → cleanup source → preview → state → run counters → actions → account/help. Source and preview form one decision; progress is a separate group. Saved history is distinct from the current run and separated across posts, likes and bookmarks. No percentage or total estimate: the page does not expose the entire accessible history.

Likes/bookmarks share the panel and controls. Action and counter copy uses removal and explains that posts remain. Mode follows the page when first opened; a link guides the user to the required page after a mode change. Confirmations identify both action and account.

The optional adult filter appears only for likes/bookmarks and starts unchecked. Its label explains that it uses X warnings and preserves items without a visible adult label. Filtered/general lists are independent; action and confirmation reflect the active filter. Panel height remains bounded with internal scrolling.

English is the initial interface language. A compact PT/EN control sits beside the minimize button and in the popup header. It switches all tool copy, status, errors, counters and confirmations, remembers the choice locally and preserves execution state. Both labels have explicit accessible names for the destination language. English source templates and Portuguese translations share interpolation names; longer Portuguese text wraps without clipping. Numbers use the active locale. Browser-native file-picker text follows browser settings.

The panel is 384 px wide and fits smaller viewports. Low-height windows use internal scrolling; the minimized control keeps status visible. Controls have at least 44 px targets, visible focus, associated labels and announced status. The popup uses the same visual identity and only opens the panel. Synthetic demo data is excluded from distribution.
